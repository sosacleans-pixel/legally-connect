# Legally Connect

Static referral site for personal injury matters in Utah. Legally Connect is a referral service, not a law firm, and does not provide legal advice.

English homepage: `index.html`. Spanish homepage: `es/index.html`. Intake chooser: `intake/` and `intake/es/`. Each case type has its own intake in English and Spanish under `intake/car/`, `intake/truck-motorcycle/`, `intake/slip-fall/`, `intake/dog-bite/`, `intake/workplace/`, and `intake/wrongful-death/`.

Intake forms are a preview only and do not send data. Phone and email coming soon. The public host name is `legallyconnect.salimheyaime.com`.
